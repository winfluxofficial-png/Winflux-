# Winflux Wallet (Android) — v0.1 testnet

**Online** wallet for the testnet: create/restore (recovery key `wflxk1-…`, compatible with `winflux/wallet/hd.py`),
balance, receive (QR + a new address on every receipt), send (value/fee review before confirming), choose the node.
Kotlin + Jetpack Compose. The seed is encrypted by a non-exportable Android Keystore key (StrongBox if available),
no cloud backup, screen protected against capture (`FLAG_SECURE`).

**Does NOT yet include**: offline payments (notes/NFC/BLE), hardware attestation, QR reading by camera, biometrics
for sending, transaction history. Testnet only.

## Verification status (honest)
- `core/` (addresses, HD, recovery key, canonical JSON, txid, signing, coin selection, fee, wallet engine)
  is pure Kotlin and was **compiled and tested on the JVM** (15 tests) against vectors generated by the Python reference code:
  the signed transaction comes out **byte-for-byte identical** (JSON, txid, Ed25519 signatures, per-byte fee).
- `net/`, `store/` and `ui/` were **neither compiled nor run** (they need the Android SDK, unavailable where it was written).
  Open it in Android Studio, sync Gradle and fix whatever the compiler points out (AGP/Compose versions may need adjusting).
- It has not been tested on a device or against a running node.

## Running
1. Start a node with the API: `python -m winflux.node.main --genesis genesis.json --api 0.0.0.0:8081 …` (see the root README). On the phone use the PC's IP on the Wi-Fi
   (`http://192.168.x.x:8081`); on the emulator, `http://10.0.2.2:8081` (default). `http` is only accepted for private IPs; otherwise, `https`.
2. Android Studio → *Open* this folder → Run. Core tests: `./gradlew :app:testDebugUnitTest` (generate the wrapper with `gradle wrapper`).

## Regenerating test vectors
The vectors (`app/src/test/.../Vectors.kt`) come from the Python code; if the tx/address/HD format changes on the node, regenerate them and run the tests.
