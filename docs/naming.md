## What the web search showed about Winflux / WFLX (2026-11-15 — this is not legal advice)
- **"Winflux" as the name of old malware:** it appears in 2004 security alerts as "Troj/Winflux-B", a trojan with
  remote access. It is old history, but the name may end up in detection lists, reputation lookups and filters.
- **WinFlux as scientific software:** a program for acquiring and analyzing atmospheric flux data used in research.
- **No cryptocurrency project named Winflux** showed up in that search (that does not prove the name is free).
- **WFLX is the call sign prefix of a TV station** (Fox 29, West Palm Beach, Florida, USA). No token with that
  ticker appeared, but there is a risk of brand and ticker confusion, mainly in the US.

## Before using the name in public (checklist)
- INPI (Brazil) and the WIPO Global Brand Database: classes 9, 36 and 42; include a phonetic search (Winflux, Winflix, Webflix).
- USPTO and EUIPO, if there is an intention to operate outside Brazil.
- Domains (.com, .org, .io, .com.br) and social media profiles.
- GitHub, CoinMarketCap, CoinGecko and CoinPaprika: name and symbol WFLX.
- Reputation lookup: the name in security tools (antivirus, DNS/URL filters).
- Review by an intellectual property lawyer.
